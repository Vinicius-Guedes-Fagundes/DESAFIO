A atividade consistiu no desenvolvimento de uma aplicação web chamada Lojão dos Games, utilizando as tecnologias React, TypeScript e Vite. O projeto foi desenvolvido em dupla, por Manassés e Vinicius, conforme a proposta do professor Ítalo.

Primeiramente, criamos o projeto utilizando o Vite e configuramos o ambiente de desenvolvimento. Em seguida, organizamos os arquivos em pastas, separando os componentes reutilizáveis das páginas da aplicação.

Durante o desenvolvimento, criamos componentes como Header, Footer, Menu, Card e Button, utilizando Props para enviar informações entre os componentes e facilitar a reutilização do código.

Para permitir a navegação entre as páginas, utilizamos o React Router DOM, criando as rotas para Início, Produtos, Sobre e Contato, além de uma página de erro 404 para endereços que não existem.

Por fim, trabalhamos na estilização da aplicação com CSS, buscando deixar o site organizado, agradável e fácil de navegar.

Com a realização dessa atividade, colocamos em prática os conceitos de React e TypeScript, aprendendo a criar componentes reutilizáveis, trabalhar com Props, organizar o projeto e desenvolver a navegação entre diferentes páginas.
